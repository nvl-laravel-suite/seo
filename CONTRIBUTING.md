# Contributing to NVL SEO

This public repository is a publication mirror of private source. Open an issue
here for a bug or proposal; include a reproduction and, if helpful, a patch.
Maintainers apply accepted changes in source and publish a mirror release.
Direct mirror pull requests do not update source. See the
[organization contribution guide](https://github.com/nvl-laravel-suite/.github/blob/main/CONTRIBUTING.md).

Changes must keep resolution, URL identity, localization, rendering, redirects, and crawl discovery consistent.

Test Actions, authorization, revisions, path races, fallback, canonical and hreflang parity, XSS-safe output, JSON-LD limits, redirects, sitemap indexes, cache invalidation, adoption, and query counts. Run Pest, Pint, PHPStan at maximum strictness, Composer validation, dependency analysis, and distribution validation.

Application imports and media integration must remain behind contracts.
